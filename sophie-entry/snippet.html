3 — One asset

Save the venue photograph as /events/assets/dome.jpg (1263 × 1175). The demo embeds it inline; on the live site reference it by path so the browser can cache it.

Notes

· The header link hides below 860 px and belongs in the existing mobile menu.
· The button is --wine, not --green: it separates “book a dinner” from “buy wine”.
· Focus states are explicit, tap target is 46 px, and the band respects prefers-reduced-motion.
· Dates are real <time datetime> values, so search engines can read them.
